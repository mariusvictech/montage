# assets — video-3

À déposer ici :

- `rush.MOV` — la vidéo face caméra, telle que sortie du téléphone ;
- `appel.MOV` — l'extrait de l'appel avec le client, à insérer pendant que tu
  en parles (dépose l'extrait déjà découpé, ou la vidéo entière en me disant à
  quel moment ça commence et combien de temps ça dure) ;
- `commande.PNG` — la capture de la commande, qui arrive après l'extrait.

`sfx/` contient les sons du montage, fabriqués par `scripts/sfx.mjs`.
Les vidéos et images restent en local : git les ignore, il faut les ajouter
avec `git add -f`.
